# 🍳 Recipe: From Idea to 8-Bit Intro

The exact workflow, start to finish. Total time: a few minutes.

```
💡 Idea  →  🤖 Claude + prompt.md  →  📋 Veo 3 prompt  →  🎥 Veo 3  →  ✂️ Optional edit  →  🎬 8-bit intro
```

---

## 🧂 Ingredients

- An AI chat: **Claude**, GPT or Gemini
- [`prompt.md`](prompt.md) (the master prompt)
- **Gemini Veo 3** access
- Optional: a video editor such as CapCut, DaVinci Resolve or Premiere

---

## 👩‍🍳 Steps

### 1. Load the master prompt
Open [`prompt.md`](prompt.md), copy the prompt inside the code block, and paste it as your first message in a new chat. For repeated use, save it as a system prompt, custom GPT or Gem.

### 2. Send your idea
One line is enough. Good ideas include a **name** and a **vibe**:

```
Intro for my coding YouTube channel DEVLOG
```

### 3. Copy the two blocks
You receive a **VEO 3 PROMPT** and a **NEGATIVE PROMPT**. Copy both.

### 4. Generate in Veo 3
Paste the prompt into Veo 3, and paste the negative prompt if your tool has that field. Set the aspect ratio to 16:9 (or 9:16 for vertical).

### 5. Review the clip
Check three things: is the text spelled right, is there constant motion, and does the final second show your name clearly?

### 6. Fix or remix
- Say **"again"** in the chat for a totally different version of the same idea.
- If only the text is wrong, keep the clip and add your name in an editor.

---

## 🎬 Optional: a 30-second video

Run the master prompt three times with different goals and join the clips:

1. `Intro for NAME` (cold open and title)
2. `again, focus on what NAME offers` (montage and stats)
3. `again, closing call to action for NAME` (final card)

Then join the three clips in your editor and add one continuous music track.

## 🛠️ Troubleshooting

| Problem | Fix |
| ------- | --- |
| Text is garbled | Say "again", or keep the clip and add the title in an editor. Shorter text works best. |
| Clip is shorter than 10 seconds | Some tools or plans cap clip length. Use the first part, then extend the clip or join a second clip. |
| Video feels slow | Add "faster pacing, a new visual event every 0.3 seconds" to the prompt. |
| Too smooth or realistic | Add "strictly 8-bit pixel art, no smooth gradients" at the very start of the prompt. |
| Same look every time | Say "again" in the same chat so the variation engine changes the palette, world and structure. |
